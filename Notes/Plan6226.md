# Plan (2026-02-06)

Guiding principle: identify the smallest set of Vol. II abstractions that supports the Vol. I
proof graph. Concretely, the development should factor through:

- finite-volume Gibbs objects on an arbitrary finite type `α`
  (Gibbs measures/kernels, replica laws, and order-parameter pushforwards);
- model-agnostic interpolation / Gaussian integration by parts (IBP) / comparison / concentration
  theorems that only depend on covariance and order-parameter structure.

## Abbreviations

- IBP: integration by parts (Gaussian).
- RS: replica symmetric.
- GGI: Ghirlanda–Guerra identities.
- RPC: Ruelle probability cascade.
- BM: Boltzmann machine.
- RBM: restricted Boltzmann machine.
- AGS: Amit–Gutfreund–Sompolinsky (Hopfield retrieval theory).

## 1. Consolidate core library infrastructure (goal: later theorems are short instantiations)

The finite-volume backbone is `SpinGlass.FiniteGibbs` together with:

- `SpinGlass.FiniteGibbs.GibbsMeasure`
- `SpinGlass.FiniteGibbs.Kernel`
- `SpinGlass.FiniteGibbs.ReplicaMeasure`

### Order parameters as first-class objects

Given `u : α → β`, define:

- `orderKernel u : Kernel (EnergySpace α) β := (FiniteGibbs.gibbsKernel (α := α)).map u`
- `orderArrayKernel u n : Kernel (EnergySpace α) (Fin n → β)` via the replica kernel.

Required API:

- measurability and pushforward identities;
- composition lemmas (so multiple order parameters can be layered without rewriting);
- lemmas describing the laws of finite patterns (pushforwards of replica measures), so
  Hopfield/perceptron/Gardner reuse a single interface.

This pattern appears in `SpinGlass.HopfieldConvolution`. The next step is to factor it out, so
Hopfield becomes an instance of “order parameter + latent convolution”.

## 2. Talagrand core theorems: Gaussian interpolation and concentration

This is the Vol. II analytic core that should drive SK/mixed \(p\)-spin/perceptron and the Hopfield
smart paths.

### (A) Gaussian concentration of `log Z` (Talagrand, Vol. I Thm 1.3.4)

- Prove a reusable lemma: if `X` is Gaussian in a real Hilbert space and `F` is Lipschitz, then
  `F X` concentrates.
- Show that `H ↦ free_energy_density N H` is Lipschitz, with constants extracted from the gradient
  bounds in `SpinGlass.FiniteGibbs.Calculus`.

Outcome: self-averaging of the free energy should reduce to a single lemma application in each
model.

### (B) Interpolation/IBP as a unified theorem

- Provide a statement for paths of the form `H_t = A t x + b t`, where `x` is Gaussian in a real
  Hilbert space. This covers \(\sqrt t/\sqrt{1-t}\) paths, and Hopfield/Gardner smart paths where
  both covariance and strength vary with `t`.
- The output should be in trace/Hessian form (the end of the current chain
  `SpinGlass.GuerraInterpolation` → `SpinGlass.GuerraIBP` → `SpinGlass.GuerraTrace`,
  with the remaining algebraic step in `SpinGlass.GuerraBound`).

Once (A) and (B) are available as model-agnostic theorems, SK and mixed \(p\)-spin should become
parameter choices rather than new proofs.

## 3. Vol. I as instances (SK, superadditivity, RS/high temperature)

With this analytic core in place, the next Vol. I milestones become direct instantiations:

- **SK / mixed \(p\)-spin** (Talagrand, Vol. II Ch. 12–14):
  instantiate the generic interpolation theorem with covariance kernel `ξ(R)` to obtain Guerra’s
  differential inequality and, after discrete approximation, the Guerra upper bound.
- **Guerra–Toninelli**:
  add the superadditivity interpolation to deduce existence of the thermodynamic limit
  \(p(\beta,h)\).
- **High-temperature / RS regime**:
  develop a reusable API for overlap concentration and fixed-point characterisations
  (in the style of `SpinGlass.HopfieldFixedPoint` for the Hopfield scalar equation).
  Central limit theorems are downstream; the first target is the concentration/uniqueness API.

## 4. Vol. II structure: GGI → ultrametricity → cascades / Parisi

The file `SpinGlass.Cascades.GhirlandaGuerra` provides a `GG₁`-type predicate interface. Next
steps:

- model-specific proofs of (approximate) Ghirlanda–Guerra identities (GGI) via small Gaussian
  perturbations and IBP (start with SK/mixed \(p\)-spin);
- abstract consequences (Panchenko invariance, ultrametricity, representation) as theorems about
  replica laws, not about spins;
- RPC / Parisi functional:
  implement the discrete \(k\)-step Parisi recursion first (more Mathlib-friendly than the PDE),
  and add enough Poisson point process / Poisson–Dirichlet infrastructure to build the cascade
  weights and verify their identities.

## 5. Hopfield, AGS, and Boltzmann machines: a unifying architecture

Treat energy-based models uniformly as instances of `SpinGlass.FiniteGibbs` on finite product
types:

- (visible-only) Boltzmann machine: `α := Config N`, energy from a weight matrix;
- restricted Boltzmann machine (RBM): `α := visible × hidden`, with the visible marginal obtained
  by integrating out the hidden units.

Two generic lemmas provide the connection:

- **Finite marginalisation**: for `E : V × H → ℝ`, define the effective energy
  \[
    E_{\mathrm{eff}}(v) := -\log \sum_{h} \exp(-E(v,h)).
  \]
  Then the visible partition function agrees with the joint one, and the visible marginal is
  Gibbs for `E_eff`.
- **Gaussian-hidden marginalisation**: Gaussian latent variables yield Hubbard–Stratonovich as a
  special case; factor the Hopfield argument in `SpinGlass.Hopfield` through a generic lemma.

Consequences:

- Hopfield is a low-rank Boltzmann machine with weights \(W = (1/N)\,\Xi\Xi^\top\).
- AGS retrieval should be expressed in terms of the low-dimensional order parameter
  `m(σ) ∈ ℝ^M` and the associated `ψ` landscape. We already have the deterministic fixed-point
  core (`SpinGlass.HopfieldFixedPoint`) and `ψ` calculus (`SpinGlass.HopfieldPsiDeriv`, etc.).
  The next step is to turn `SpinGlass.HopfieldLocalization` from a statement-only file into a
  proof development by combining:
  - HS / `ψ`-density (`SpinGlass.HopfieldConvolution`);
  - Laplace principle / concentration around maximisers of `ψ`;
  - probabilistic control of pattern means and symmetries (start with Gaussian patterns;
    universality to Bernoulli/Rademacher later).

## 6. Concrete coding milestones (proposed order)

- **Milestone 1**: factor out a generic `orderParameterKernel` / `orderParameterArrayKernel` API
  (Hopfield becomes an instance; perceptron/Gardner reuse the same interface).
- **Milestone 2**: land Gaussian concentration for `log Z` as a reusable lemma, plus the “Lipschitz
  via `FiniteGibbs` gradient bounds” API.
- **Milestone 3**: complete the generic interpolation → IBP → trace/Hessian chain, so
  `SpinGlass.GuerraBound` plugs in directly.
- **Milestone 4**: complete one Vol. I main theorem end-to-end as an instance (e.g. RS Guerra bound
  for SK, or Hopfield `ψ`-based localisation in a well-controlled regime).
- **Milestone 5**: add the marginalisation API for product models (BM/RBM connection), express
  Hopfield as low-rank BM, and reuse the generic lemmas.
- **Milestone 6**: start the GGI proof for SK/mixed \(p\)-spin (perturbation + IBP), then push
  abstract consequences (ultrametricity, cascades, Parisi recursion).
