# Plan (2026-02-06)

Guiding principle: identify the smallest set of Vol. II abstractions that supports the Vol. I
proof graph. Concretely, the development should factor through:

- finite-volume Gibbs objects on an arbitrary finite type `α`
  (Gibbs measures/kernels, replica laws, and order-parameter pushforwards);
- model-agnostic interpolation / Gaussian integration by parts (IBP) / comparison / concentration
  theorems that only depend on covariance and order-parameter structure.

## Abbreviations

- IBP: integration by parts (Gaussian).
- RS: replica symmetric.
- GGI: Ghirlanda–Guerra identities.
- RPC: Ruelle probability cascade.
- BM: Boltzmann machine.
- RBM: restricted Boltzmann machine.
- AGS: Amit–Gutfreund–Sompolinsky (Hopfield retrieval theory).

## Status (already in the repository)

- The finite-volume Lipschitz estimate for free energies is already available as
  `SpinGlass.FiniteGibbs.abs_free_energy_density_sub_le` (see `SpinGlass.FiniteGibbs.Calculus`).
- The SK Guerra derivative is already provided in trace/Hessian form as
  `SpinGlass.hasDerivAt_guerraPhi_eq_trace_integral` (see `SpinGlass.GuerraPipeline`).
- Finite marginalisation on product types (BM/RBM visible marginal as Gibbs of a log-sum-exp
  energy) is already implemented in `SpinGlass.FiniteGibbs.Marginal`, with the measure-level
  statement `map_fst_gibbsMeasure_eq_gibbsMeasure_marginalEnergy`.
- Hopfield order-parameter pushforwards are already packaged as kernels in
  `SpinGlass.HopfieldConvolution` (e.g. `hopfieldOverlapKernel`, `hopfieldOverlapArrayKernel`).
- The `GG₁` predicate and its kernel-level formulation are already developed in
  `SpinGlass.Cascades.GhirlandaGuerra` (including SK specialisations such as `SK_GG1_gibbsKernel`).

## 1. Consolidate core library infrastructure (goal: later theorems are short instantiations)

The finite-volume backbone is `SpinGlass.FiniteGibbs` together with:

- `SpinGlass.FiniteGibbs.GibbsMeasure`
- `SpinGlass.FiniteGibbs.Kernel`
- `SpinGlass.FiniteGibbs.ReplicaMeasure`

### Order parameters as first-class objects

Given `u : α → β`, define:

- `orderKernel u : Kernel (EnergySpace α) β := (FiniteGibbs.gibbsKernel (α := α)).map u`
- `orderArrayKernel u n : Kernel (EnergySpace α) (Fin n → β)` via the replica kernel.

Required API:

- measurability and pushforward identities;
- composition lemmas (so multiple order parameters can be layered without rewriting);
- lemmas describing the laws of finite patterns (pushforwards of replica measures), so
  Hopfield/perceptron/Gardner reuse a single interface.

This pattern appears in `SpinGlass.HopfieldConvolution`. The next step is to factor it out, so
Hopfield becomes an instance of “order parameter + latent convolution”.

## 2. Talagrand analytic core: interpolation and Gaussian functional inequalities

This is the Vol. II analytic core that should drive SK/mixed \(p\)-spin/perceptron and the Hopfield
smart paths.

### (A) Gaussian Poincaré / variance bounds (primary target)

For the spin-glass applications, the first essential statement is a variance estimate, not an
exponential tail bound.

- Prove a Gaussian Poincaré inequality for `ProbabilityTheory.IsGaussian μ` on a real Hilbert
  space (variance controlled by the squared norm of the Fréchet derivative, expressed using the
  covariance operator / Cameron–Martin structure).
- Apply it to `H ↦ SpinGlass.FiniteGibbs.free_energy_density n H`, using the existing derivative
  bounds from `SpinGlass.FiniteGibbs.Calculus`, to obtain \(L^2\) self-averaging statements.

This should be set up so that, given a model-specific Gaussian disorder `H`, the variance bound is
an instantiation of a generic lemma + a single norm estimate.

### (A′) Optional: exponential tails (secondary target)

Talagrand’s Vol. I Thm 1.3.4 is usually stated as a subgaussian tail bound for Lipschitz
functionals. Formalising this in Mathlib style may require additional infrastructure (e.g. a
log-Sobolev/Herbst argument or Gaussian isoperimetry). This should be treated as a separate,
long-term deliverable, not a blocking dependency for Vol. I existence results.

### (B) Interpolation/IBP, structured as three lemmas

Avoid a single monolithic “affine Gaussian path” theorem. Instead, keep the API stratified into
three reusable statements:

- **(B1) Differentiation under the integral sign** for `t ↦ 𝔼[free_energy_density n (H t)]`,
  with hypotheses expressed as explicit integrability/dominating conditions.
  (Prototype: `SpinGlass.GuerraInterpolation`.)
- **(B2) Gaussian IBP rewrite** expressed through the Hilbert/covariance-operator IBP API.
  (Prototype: `SpinGlass.GuerraIBP`, using
  `ProbabilityTheory.IsGaussian.integral_inner_mul_eq_integral_fderiv_covarianceOperator_polyGrowth`.)
- **(B3) Algebraic reduction to trace/Hessian form** at the level of covariance kernels / order
  parameters. (Prototype: `SpinGlass.GuerraTrace` and the kernel trace computations in
  `SpinGlass.Defs` / `SpinGlass.GuerraBound`.)

Once (A) and (B) are available as model-agnostic theorems, SK and mixed \(p\)-spin should become
parameter choices rather than new proofs.

## 3. Vol. I as instances (SK, superadditivity, RS/high temperature)

With this analytic core in place, the next Vol. I milestones become direct instantiations:

- **SK / mixed \(p\)-spin** (Talagrand, Vol. II Ch. 12–14):
  instantiate the generic interpolation theorem with covariance kernel `ξ(R)` to obtain Guerra’s
  differential inequality and, after discrete approximation, the Guerra upper bound.
- **Guerra–Toninelli**:
  add the superadditivity interpolation to deduce existence of the thermodynamic limit
  \(p(\beta,h)\).
- **High-temperature / RS regime**:
  develop a reusable API for overlap concentration and fixed-point characterisations
  (in the style of `SpinGlass.HopfieldFixedPoint` for the Hopfield scalar equation).
  Central limit theorems are downstream; the first target is the concentration/uniqueness API.

## 4. Vol. II structure: GGI → ultrametricity → cascades / Parisi

The file `SpinGlass.Cascades.GhirlandaGuerra` provides a `GG₁`-type predicate interface. Next
steps:

- model-specific proofs of (approximate) Ghirlanda–Guerra identities (GGI) via small Gaussian
  perturbations and IBP (start with SK/mixed \(p\)-spin);
- abstract consequences (Panchenko invariance, ultrametricity, representation) as theorems about
  replica laws, not about spins;
- Parisi functional: implement the discrete \(k\)-step recursion first (an analytic object that
  does not require Poisson–Dirichlet infrastructure). Construction of RPC weights via Poisson
  point processes / Poisson–Dirichlet should be treated as a separate infrastructure project.

## 5. Hopfield, AGS, and Boltzmann machines: a unifying architecture

Treat energy-based models uniformly as instances of `SpinGlass.FiniteGibbs` on finite product
types:

- (visible-only) Boltzmann machine: `α := Config N`, energy from a weight matrix;
- restricted Boltzmann machine (RBM): `α := visible × hidden`, with the visible marginal obtained
  by integrating out the hidden units.

Two generic lemmas provide the connection:

- **Finite marginalisation**: for `E : V × H → ℝ`, define the effective energy
  \[
    E_{\mathrm{eff}}(v) := -\log \sum_{h} \exp(-E(v,h)).
  \]
  Then the visible partition function agrees with the joint one, and the visible marginal is
  Gibbs for `E_eff`.
- **Gaussian-hidden marginalisation**: Gaussian latent variables yield Hubbard–Stratonovich as a
  special case; factor the Hopfield argument in `SpinGlass.Hopfield` through a generic lemma.

Consequences:

- Hopfield is a low-rank Boltzmann machine with weights \(W = (1/N)\,\Xi\Xi^\top\).
- AGS retrieval should be expressed in terms of the low-dimensional order parameter
  `m(σ) ∈ ℝ^M` and the associated `ψ` landscape. We already have the deterministic fixed-point
  core (`SpinGlass.HopfieldFixedPoint`) and `ψ` calculus (`SpinGlass.HopfieldPsiDeriv`, etc.).
  The next step is to turn `SpinGlass.HopfieldLocalization` from a statement-only file into a
  proof development by combining:
  - HS / `ψ`-density (`SpinGlass.HopfieldConvolution`);
  - Laplace principle / concentration around maximisers of `ψ`;
  - probabilistic control of pattern means and symmetries (start with Gaussian patterns;
    universality to Bernoulli/Rademacher later).

## 6. Deliverables and criteria

We aim for each milestone to be phrased as a PR-sized deliverable, and should end with:

- a stable API (definitions + simp/rewriting lemmas in the expected normal forms);
- at least one downstream instantiation in an existing model file.

### Near-term

- **Milestone 1 (order-parameter kernels)**:
  extract the generic pattern already present in `SpinGlass.HopfieldConvolution` and place it in a
  configuration-agnostic file (likely under `SpinGlass.FiniteGibbs`), providing
  `orderKernel` / `orderArrayKernel` together with composition and “finite pattern law” lemmas.
  Acceptance: Hopfield code reduces to instantiations of this generic API.
- **Milestone 2 (Gaussian Poincaré + \(L^2\) self-averaging)**:
  add a variance inequality for `IsGaussian` laws on Hilbert spaces, expressed through the
  covariance operator / Cameron–Martin structure, and derive a reusable corollary for
  `FiniteGibbs.free_energy_density` using existing derivative bounds.
  Acceptance: each model gets an `L^2` self-averaging lemma by a short instantiation.
- **Milestone 3 (abstracted interpolation lemmas)**:
  keep the interpolation argument split into (B1) dominated differentiation, (B2) IBP rewrite,
  and (B3) trace/kernel reduction. Start by refactoring the SK development so that the
  `SpinGlass.Guerra*` files are visibly instances of these three lemma interfaces.
  Acceptance: `SpinGlass.hasDerivAt_guerraPhi_eq_trace_integral` remains a one-line lemma obtained
  by combining (B1)–(B3) after refactoring, and the three components are usable independently.
- **Milestone 4 (one end-to-end theorem)**:
  complete one Vol. I main statement end-to-end as an instance (e.g. an RS bound for SK, or a
  Hopfield localisation theorem in a regime where the existing `ψ`-representation is sufficient).
  Acceptance: the proof script is mostly instantiations of Milestones 1–3 plus a clearly isolated
  algebraic/model-specific core.

### Medium-term

- **Milestone 5 (energy-based models / latent variable elimination)**:
  build on `SpinGlass.FiniteGibbs.Marginal` to package “integrate out hidden variables” as a
  reusable tool (BM/RBM interface), and factor Gaussian-hidden marginalisation so that
  Hubbard–Stratonovich is a specialization of a generic lemma.
  Acceptance: Hopfield can be presented as a low-rank BM and linked to the existing convolution
  formalism without duplicating measure-theoretic arguments.
- **Milestone 6 (GGI for SK/mixed \(p\)-spin)**:
  prove an approximate GGI statement via perturbations and IBP, producing a `GG1Kernel` statement
  at the level of Gibbs replica samplers.
  Acceptance: the result is stated in the `SpinGlass.Cascades.GhirlandaGuerra` language and plugs
  into downstream abstract consequences.

### Long-term infrastructure (non-blocking for Vol. I existence theorems)

- Exponential tail bounds for Lipschitz functionals of Gaussians (Talagrand Thm 1.3.4 form).
- Poisson point process / Poisson–Dirichlet / RPC constructions, used for full Parisi theory and
  cascade representations.
